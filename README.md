# Fathom

Fathom is a bioluminescent deep-sea maze chase. Swim through a dark trench, graze plankton to brighten your light, and use sonar and ink to manage the hunters closing in.

## Install and run

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. Build the static site with `npm run build`; the deployable site is written to `dist/`. Preview that build with `npm run preview`.

## Controls

- Arrow keys or WASD: swim; Space: sonar; Shift: ink.
- Enter or Space: select; Escape or P: pause/back; M: mute.
- On the title and pause menus, use Up and Down to choose an item.
